# RFC-0013 fase 01 — validação da lane

Estado: implementação em andamento. Os testes isolados não liberam o gate E2, em particular porque a autorização real do Kernel e o wiring compartilhado ainda não estão conectados.

Na raiz da worktree, execute `node --test Tests/Harness/memory/service.test.mjs src/memory/store.test.mjs` para os testes de domínio e regressão v1. `sh Tests/Harness/memory/run-swift-tests.sh` compila somente os arquivos isolados num diretório temporário, executa os cenários Swift e os testes de interoperabilidade JS/Swift e remove esse diretório. Os testes usam diretórios descartáveis e imprimem nomes e resultados, sem conteúdo privado. O teste de lock inicia processos reais, mantém uma transação aberta e encerra o detentor com SIGKILL; os dois runtimes acessam o mesmo SQLite sidecar, nota e journal. Exige Node compatível com `node:sqlite` (a CI New Harness usa 22.14.0), Swift e SQLite3.

A suíte usa uma função de fixture na fronteira de policy e, portanto, não comprova AUTH-REAL. O teste de journal reconstrói o estado pendente de crash; não é teste de crash em todos os pontos de persistência. A comparação de recall entre runtimes usa uma fixture, não um corpus de paridade completo. O espelho legível `MEMORY.md` e o estado são arquivos separados; a intenção persistida permite reconciliá-los no próximo acesso. Ainda falta testar SIGKILL em cada ponto dessas escritas. Registre no relatório integrado `pocketwiki_sha`, `pocketkernel_sha` e `middlewareauth_sha` sem tokens ou paths pessoais.

O host deve autenticar a credencial e consultar a ACL/owner E0/E1 antes de cada acesso. A facade JS exige `policy(auth, {namespace, scope, personal}) -> Promise<boolean>` e a Swift exige `Policy(PocketMemoryAuthorization, PocketMemoryNamespace, String, Bool) async throws -> Bool`. Ausência/falha da porta retorna indisponibilidade e recusa retorna negação; o adaptador não pode aceitar identidade ou scopes escolhidos pelo payload. A porta ainda não está conectada ao Kernel. O integrador deve encaminhar mutações pelo ledger/CAS/receipt do runtime e conectar snapshot/stream à boundary e à retenção R1; não registrar handlers em produção antes de validar essa integração.

Não alterar o runner global nesta lane.
